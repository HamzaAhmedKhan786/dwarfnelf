# Contributing
Proposals require design doc/ADR, test plan, reproducible benchmark for performance changes, threat review for tools/data, license provenance and docs updates. Never commit secrets, private corpora or model weights. Follow formatting/lint and signed-off release gates.

Use the [backend checks](README.md#develop-the-backend) and record any OS policy blocks separately from compilation or test failures. Update the [API contract](docs/API_CONTRACT.md) and OpenAPI when routes change. Keep personal development skills and agent playbooks in ignored local directories.

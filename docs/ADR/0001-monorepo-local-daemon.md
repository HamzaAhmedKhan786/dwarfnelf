# ADR-0001: Monorepo, bundled installer, independent daemon
**Decision:** One GitHub repository `dwarfnelf`, one default bundled desktop installer and optional daemon-only package. Rust daemon runs independently from Tauri desktop and CLI, communicates over authenticated loopback or IPC. Rationale: unified versioning, easy install, headless operation, testability, shared contracts. Tradeoffs: larger release artifacts and native cross-platform packaging burden. Alternatives rejected: browser-only hosted service (violates offline-first); requiring two user downloads (poor onboarding); embedding inference in UI process (poor isolation).

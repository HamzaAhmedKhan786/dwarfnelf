# Risk Register
R1 Dense-model splitting cannot preserve arbitrary model semantics: mitigation architecture-specific MoE/conditional execution and explicit experimental labeling.
R2 8 GB CPU speed impractical for huge models: mitigation compatibility planner, quantization, honest benchmarks and refusal of infeasible plans.
R3 SSD expert streaming bottleneck: mitigation prefetch/cache experiments, disk I/O telemetry, baseline comparisons.
R4 RAG hallucination/outdated legal/medical sources: provenance, dates, citation verification, abstention and human review.
R5 Jev hosted availability/licensing: optional adapter; offline local decisions mandatory.
R6 Unsafe agents: sandbox, explicit permissions, approval and audit.
R7 Packaging cross-platform native libraries: pinned builds, CI matrix and signed installers.
R8 Data licensing/privacy: manifest validation, user consent, no redistribution without rights.
R9 Benchmark overfitting: held-out sets, confidence intervals, preregistered metrics.
